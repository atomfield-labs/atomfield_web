# AtomField

A distributed job scheduler and directed acyclic graph (DAG) execution engine for computational chemistry and materials science simulations.

---

## Architecture Overview

AtomField coordinates complex, multi-stage simulation workflows across decoupled API servers, background worker clusters, and durable storage backends.

## Key Features

- **DAG Pipeline Orchestration**: Submits arbitrary workflow graphs with automatic root node identification and dependency edge resolution.
- **Fan-In Concurrency Control**: Uses PostgreSQL row-level locks (`SELECT ... FOR UPDATE`) during downstream dependency evaluation to prevent race conditions when multiple parent jobs complete simultaneously.
- **Upstream XCom Propagation**: Downstream dependent tasks automatically receive output results and parameters generated by upstream parents.
- **Execution Sandboxing**: Supports running arbitrary user scripts inside isolated Docker containers with memory limits and read-only source mounts, as well as native semi-empirical drivers (e.g. GFN2-xTB).
- **Workspace File Management**: Isolates input geometry assets (`.xyz`, `.cif`, `.pdb`, `.sdf`) and execution artifacts per session, enabling real-time log polling and compressed archive downloads.
- **Interactive Visual Editor**: React Flow canvas supporting drag-and-drop workflow authoring, live execution status rendering, parameter tuning, and real-time log inspection.

## Getting Started

### Prerequisites

- [Docker](https://www.docker.com/) and Docker Compose
- [uv](https://docs.astral.sh/uv/) (for local host development)
- Python 3.11+
- Node.js 18+ (for frontend)

### Running with Docker Compose

To boot the full backend stack (PostgreSQL, Redis, API, and Worker):

```bash
docker compose up --build
```

- API Server: `http://localhost:8000`
- Interactive API Documentation: `http://localhost:8000/docs`
- Health check: `http://localhost:8000/health`

### Running the Frontend

```bash
cd frontend
npm install
npm run dev
```

The web dashboard and pipeline canvas will be accessible at `http://localhost:5173`.

## API Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Service liveness probe |
| `POST` | `/api/jobs/submit` | Enqueue a standalone simulation job |
| `POST` | `/api/jobs/pipeline/submit` | Submit a DAG pipeline of jobs |
| `GET` | `/api/jobs/{job_id}` | Retrieve job execution status and output |
| `GET` | `/api/jobs/{job_id}/logs` | Stream live stdout logs and list artifacts |
| `GET` | `/api/jobs/{job_id}/artifacts/download` | Download session artifacts as a `.zip` archive |
| `POST` | `/api/files/upload` | Upload and parse molecular structure files (`.xyz`, `.cif`, etc.) |
| `GET` | `/api/scripts/available` | List available simulation scripts from manifest |
